# Contributing

Thanks for your interest in improving Project Workspace Initializer.

## Before opening a pull request

1. Keep changes focused on the script or its documentation and tests.
2. Check Bash syntax with `bash -n auto-folder`.
3. Run the tests with `bash tests/auto-folder.bash`.
4. Describe the behavior changed and any relevant test results in your pull
   request.

For significant changes, open an issue first to discuss the proposal.

## Reporting a bug or requesting a feature

Use the GitHub issue templates and include enough detail to reproduce the
problem or explain the use case.
